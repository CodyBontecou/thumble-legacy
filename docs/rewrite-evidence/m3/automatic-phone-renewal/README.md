# Automatic native phone renewal

Local source `69a67e1`, public source `5e8ba80d2e8dcbdab0b4e13e6669c2410762e415`, enables explicit control-v6 renewal in both bundled phone apps. The clients retain the native touch engine, preserve engine sequencing, install fresh packet counters and require the receiver's acknowledgment on each new scope. Scheduling uses continuous time captured before grant I/O; old wall/continuous deadlines remain authoritative after the reply. Android prepares on its worker and commits on the next UI sample; Swift commits on the UI actor. A known TLS fallback is retained. Bearer credentials are not resent or exported through React.

Local and isolated public projection checks pass 85 Swift and 106 Android tests, zero native skips, Android AAR/lint and both iOS SDK builds. The public projection additionally passes 99 Rust unit cases, 14 process cases, strict Clippy/formatting and standalone CLI/service/MCP packaging. Portable checks pass 107 cases; the compiled package case is intentionally skipped there and passes separately (46 Bun assertions including its official Node SDK driver). The required stack-safety gate passes 55 tests and both retained app builds.

Real TLS/native-IPC witnesses hold a button and trigger for at least 75 seconds in both UDP and forced TLS fallback modes. Each records two accepted source-counter resets and zero neutral pulses under a 350 ms input TTL, then verifies acknowledged neutral release and a fresh reconnect. Local SDK proof: Swift UDP 75.012 seconds/4322 samples, fallback 75.012/4338; Kotlin UDP 75.006/3653, fallback 75.005/4031. The isolated public projection repeats both modes independently; exact metrics are in the manifest.

The bundled Android app passes all ten instrumentation cases with zero skips. Its actual system-pointer hold lasts 75.163 seconds across two renewals and 1988 held output samples while the actual JS queue remains blocked. Native feedback continues, both fingers release correctly, and the second connection starts neutral. The final bundled UIKit run passes all five cases, with a 75.007-second native semantic hold, two renewals and 4068 held samples on its real display-link loop, followed by native release and vault-backed reconnect. These are recording witnesses, not physical gameplay or iOS system-finger injection.
