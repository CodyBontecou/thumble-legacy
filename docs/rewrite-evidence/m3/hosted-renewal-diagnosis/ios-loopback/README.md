# Cold simulator HTTP diagnostic

Local `1b2ab97`, public `6a12442fe45f43d350ab5201c9ed941993ad41cb`, adds a temporary minimal UIKit simulator app plus Python-owned localhost HTTP server. It compares shared and ephemeral URLSession clients across three process launches with unchanged six-second request deadlines, no retry/skip and exact success checks. It creates and deletes only its own simulator. There is no React Native, SDK/native TLS enrollment, trust or input path in this diagnostic; its success cannot substitute for bundled-app acceptance.

The five-file snapshot also includes the eight-consecutive-attempt Windows gate. Capsule SHA-256 `7e00b72dfef80cb17c1ffb80742b7140e57617a22a39966beae6339e3ea225c3`; sole public parent `9e328dbb34e6fe82adb46a75a93e085e28a3aa86`; tree `b53773562640f46a88b501edb1cb7deb5098bca8`. Full recursive leaf diff, modes/blob hashes and parent were verified before publication. Private history/evidence, credentials and builds are excluded.

Local iOS 26.5: all six requests succeed, across three launches, with both clients. Two result-admission tests reject arbitrary text, extra fields, wrong identities/types/counts and oversized error codes. The isolated source passes those tests, Swift simulator type checking and workflow lint. Workspace gates pass 159 source cases / 2,983 assertions. Retained stack verification passes 55 constrained-stack tests and both retained app builds. Hosted diagnostic run [39820408669](https://github.com/CodyBontecou/Thumble/actions/runs/39820408669), job `119969876521`, is live under the app workflow's Xcode 26.3 / macOS 15 baseline; its result is not yet counted as a pass.

The motivating terminal app run `39811471888` fails before its synthetic receiver starts: URLSession.shared times out contacting `/begin`; no enrollment checkpoint is emitted. Minimal shared-vs-ephemeral failure would isolate a simulator/Foundation HTTP issue; both succeeding would shift investigation to bundled-app/harness state. Apple documents that simulator local-network privacy differs from devices ([TN3179](https://developer.apple.com/documentation/technotes/tn3179-understanding-local-network-privacy)). An older Apple DTS report describes a shared-session simulator regression resolved by ephemeral sessions ([thread 777999](https://developer.apple.com/forums/thread/777999)); it concerns iOS 18.4 and is only motivation for the controlled comparison, not proof of the current iOS 26.2 cause. Product TLS or security settings have not been changed on that assumption.
