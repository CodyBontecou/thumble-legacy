# Owned native editing adapter

The explicit native command validates v5 source, applies retained native operations to temporary models, preserves the canonical landscape contract and returns same-codec before/after projections with source hash and invocation identity. It reconciles eight appearance states when custom controls are added or removed. Portrait/orientation input rejects, and a package-backed result cannot lose its reference silently. Nullable default selection is preserved independently of the temporary legacy-model fallback.

The Rust host adapter validates operation scope, exact executable owners, response correlation, final schema and bank reconciliation through independent Rust resolution of all eight states. Its transient landscape mirrors exist only for legacy delta guards; the lossless writer applies validated changes to original bytes. Opaque root/profile metadata and original large-integer/precise-decimal spellings survive. A preexisting part-output guard bug is corrected to compare part outputs rather than whole control objects.

Six native packets and actual merged destinations are frozen. Native tests check geometry/output ownership, haptic intensity across all eight states, custom add/remove identities, scheme changes and null-default selection. Rust cases validate scoped responses, reject nonce/source/path/changed/before/output tampering, and use a recording subprocess sentinel to prove portrait/orientation rejection precedes helper execution. Android independently decodes every result and compares display preparation with native output without package lookup. These are model/render-preparation checks, not pixel or physical-device acceptance.

Verification passes the full shared-tree Rust gate (548 tests, three existing native-dependent ignored), final three focused Rust tests, seven isolated native tests, 41 constrained-stack cases, both Apple Debug builds, 207 Android unit tests plus device-test assembly, and real native process acceptance (six exact responses, five mixed/unexpected inputs, portrait and legacy-document rejection). The final focused Rust rerun adds only a test-subprocess marker after the full gate. Tested source and original log hashes, isolated overlays and helper hash are in verification.json. The older projection-merge generator-file hash is refreshed; its fixture data stays unchanged.

This adds the local edit bridge, not owned authority/CLI/MCP draft dispatch, phone editing activation, automatic migration or runtime publication. No existing profiles or deployed services changed. Physical haptics, input latency, live WoW and final native preview acceptance remain outstanding. Concurrent unrelated shared-checkout changes are excluded from the isolated Apple/Android builds and from this commit.
