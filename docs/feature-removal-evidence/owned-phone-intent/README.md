# Owned phone intent and staging evidence

The Rust protocol codec defines a bounded canonical layout intent instead of a full customization replacement. It accepts scoped geometry/visibility/lock/stacking changes, removal UUIDs and optional color preference; paths, packages, outputs, appearance replacement and orientation variants cannot enter the request. Canonical UUIDs, duplicate JSON keys, owner uniqueness, count/byte limits and scalar bounds are checked. Fourteen frozen cases and a hashed structural schema define the unactivated contract.

The backend resolves every target against an owned source at the exact configuration revision before creating private storage. Deterministic draft/commit/operation IDs and a whole-intent marker prevent changed-prefix reuse. Existing durable operation records resume interrupted native work; matching committed IDs replay their original result. Staging itself neither installs authority bytes nor acknowledges a peer. Authentication, revalidation, release barriers and CAS remain required in future runtime wiring.

The complete isolated Rust gate passed 605 tests (3 new protocol cases and 5 new staging cases), with 3 existing ignored tests. Regressions cover strict scalar decoding, the shared matrix, stale/missing targets before storage, interrupted-batch resumption, altered whole-intent refusal, paint/resource/metadata preservation, staging replay and commit receipts. The final fixture/schema verifier adds its schema hash check after the full gate and is recorded separately.

The developer harness uses the real native owned-operation bridge to move/rotate/reveal a control, delete a custom control and change color preference. It checks exact eight-state paint retention apart from the deleted owner, resource/local-launch retention, executable declarations and unaffected binding maps, raw precise metadata, stage replay and prepared commit/replay at revision 42. Its only state is an explicitly seeded private fixture with no live input owner. Native-source hashes cover 131 unchanged source/project files; 41 constrained stack tests and macOS/iOS Debug builds passed.

Controller-message dispatch, revision/result snapshots, authenticated peer job handling and iOS/Android journal adapters are not yet implemented. Profile-format offers remain [4]. Automatic migration, phone activation, remaining skin/desktop removal and physical acceptance remain outstanding. This evidence proves the codec/private staging backend, not shipped on-phone synchronization.
