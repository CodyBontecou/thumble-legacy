# Owned portable codec evidence

The pure version-5 portable container preserves raw numeric spellings, future safe metadata, canonical controls, all eight appearance states and validated resource tables. It excludes local launch targets and recursively refuses nonportable metadata. Resource exceptions are confined to validated profile tables/references; escaped property names cannot bypass scope checks. Selection validates original content before filtering, maintains default status and scopes binding aliases correctly. A separate schema and exact-UTF-8 digest avoid changing the version-4/JCS contract.

The final isolated Rust gate passed 583 tests (10 new codec cases), with 3 existing ignored tests, strict formatting/lints and host/MCP checks. Regressions cover exact roundtrip/frozen output, source immutability, single-profile binding/default behavior, absent per-profile-map aliases, credentials and binary refusal, pointer-name resource disguises, large valid resources, inner versus outer whitespace, correlated hash/version/catalog tampering, duplicate keys, correctly rehashed invalid data and the complete container byte ceiling. The standalone Python fixture verifier independently checks the exact embedded document hash and frozen source/output hashes.

The constrained native stack gate passed 41 tests and macOS/iOS Debug builds. Its 131 tracked source/project files are unchanged from the base commit; no Apple model, inline-size budget or stack workaround is introduced. Source and log hashes identify the tested inputs. The final fixture verifier adds an independent checksum check after the full Rust run; fixtures.txt records that final script run.

This batch does not activate CLI/MCP owned import/export, version-5 phone transfer or automatic migration. Native response validation, authority import transactions with deterministic copy IDs/local-launch preservation, peer reconciliation, runtime retirement and final device/latency acceptance remain required.
