Deployed infrastructure needs a separate live inventory before retirement: service identifiers, routes, shared storage, OAuth credentials, jobs, and backup/retention requirements cannot be proven from source files alone.

Apple hosted transport retirement: `BuilderArtifactFetch.swift`, `BuilderArtifactShare.swift` and `IOSBuilderArtifactPickup.swift` are removed. `PendingProfileRecovery` and `IOSBuildRecovery` provide read-only legacy export; the former pruning store exists only as `Tests/LegacyIOSPendingBuilderArtifactStore.swift`. `MacSharedKeypadImport` retains local file validation/review/import. Shared `PortableProfileArtifact` remains for ordinary local import/export. Legacy `ProfileArtifactAdoption` wire shapes are reserved for decoding and nonmutating retirement errors; receiver assemblers/commit jobs and capability advertisements are removed. Existing receipt bytes remain in legacy storage without new adoption writes.
