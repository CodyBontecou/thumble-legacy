# Legacy configuration migration fixtures

These are actual v4 inputs, native preparation packets, and Rust-composed v5 destinations. The source profiles come from the frozen pre-removal migration cases; the explicit-landscape case adds a second executable layout with distinct opaque metadata and a different stored appearance preference. The canvas cases cover a known legacy alias and an omitted canvas; an unknown frame requires recovery. Native request profiles also contain beyond-u64 and precise-decimal metadata. The bounded native helper returns only known before-layout/after-profile projections, source/package digests, identities and review reasons. Original bytes stay authoritative.

`Tests/LegacyProfileMigrationTests.swift` regenerates profile/request/response files into `build/LegacyConfigurationMigration`, with exact frozen comparison. Rust's `legacy_configuration_migration` test streams those responses into real version-4 configuration documents, preserves selected raw layout metadata, removes retired fields, validates complete version-5 destinations, and writes source/destination files into `Host/target/LegacyConfigurationMigration`. Tests also cover correlation failures, a missing package, another variant's controls, changed declarations/order, missing resources, and failure after an earlier profile was staged. Apple and Android independently read all five converted destinations and compare retained appearance/output behavior with native staging.

The package in the portrait request is a deterministic archive of the frozen resolver specimen with its descriptors corrected to match the existing payload bytes. The original pre-removal fixture is unchanged. This archive is test input, not a published skin or a product authoring workflow.

Use `scripts/verify-legacy-preparation-bridge.py BUILT_BRIDGE` for real native process acceptance, including mixed-command rejection. The manifest pins generator sources, inputs and outputs. The missing-package case intentionally has no destination. Format-5 startup, ordinary import, phone offers, persistence, backup/CAS/rollback, and pending-edit migration remain gated; these files do not prove live migration acceptance.
